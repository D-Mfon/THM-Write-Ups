Defensive Security Intro

Overview
The Defensive Security Intro room provided an introduction to the blue team side of cybersecurity. Unlike offensive security, which focuses on identifying and exploiting vulnerabilities, defensive security focuses on protecting systems, detecting threats, and responding to incidents.

Objectives
* Understand the role of defensive security
* Learn how organizations monitor threats
* Explore common blue team functions
* Gain awareness of security operations and incident response

 Key Concepts Learned

-Security Operations Center (SOC)
A Security Operations Center (SOC) is responsible for monitoring and analyzing security events within an organization. SOC analysts investigate suspicious activities, identify threats, and respond to security incidents.

-Threat Intelligence
Threat intelligence involves collecting and analyzing information about cyber threats to help organizations anticipate and defend against attacks.

-Digital Forensics and Incident Response (DFIR)
DFIR focuses on investigating security incidents, collecting evidence, determining the cause of an attack, and helping organizations recover from breaches.

-Security Information and Event Management (SIEM)
SIEM tools collect and analyze logs from multiple systems to detect suspicious activities and generate alerts.

Skills Gained
* Understanding of blue team operations
* Familiarity with SOC workflows
* Basic knowledge of threat intelligence
* Awareness of incident response processes
