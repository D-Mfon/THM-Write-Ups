# Vulnerabilities 101

## Overview

The Vulnerabilities 101 room introduced the concept of security vulnerabilities, how they are discovered, categorized, and managed within cybersecurity environments.

## Objectives

* Understand what vulnerabilities are
* Learn how vulnerabilities are identified
* Explore vulnerability databases and scoring systems
* Understand the importance of vulnerability management

## Key Concepts Learned

### Security Vulnerabilities

A vulnerability is a weakness in software, hardware, or system configuration that could be exploited by an attacker.

### Common Vulnerabilities and Exposures (CVE)

The CVE system provides a standardized way to identify and track publicly disclosed vulnerabilities.

### Common Vulnerability Scoring System (CVSS)

CVSS is used to measure the severity of vulnerabilities based on factors such as exploitability and impact.

### Vulnerability Databases

Security professionals use vulnerability databases to research known weaknesses and determine remediation strategies.

Examples include:

* CVE Database
* NVD (National Vulnerability Database)
* Vendor Security Advisories

### Vulnerability Management Process

1. Identify vulnerabilities
2. Assess risk
3. Prioritize remediation
4. Apply fixes or mitigations
5. Verify remediation effectiveness

## Skills Gained

* Understanding of vulnerability disclosure processes
* Familiarity with CVE and CVSS systems
* Ability to research known vulnerabilities
* Awareness of vulnerability management workflows

## Reflection

This room provided valuable insight into how security professionals track and manage vulnerabilities. Understanding vulnerability management is essential for reducing organizational risk and maintaining secure systems.
